# Neon Coast Cover Studio

Neon Coast Cover Studio is an offline browser app that turns any photo and a caption into original
multi-panel GTA-style cover art, exported as PNG in 1080x1080, 1080x1350 and 1920x1080.
The cover art uses original canvas drawing with a sunset and neon grade and no third-party game art.

## Run it

```
node serve.ts
```

`node main.ts` writes the app, screenshots and dossier into `MAKEFUN_OUTPUT_DIR`.
